# Contributors

Thank you to everyone who helps make this guide better. Contributions are tracked here as they are merged.

## How to be added

Open a pull request that:
- fixes a typo, stale number, or broken link, or
- adds a case study, diagram, or real-world failure story, or
- improves a module or template.

Then add your name and GitHub handle to this file under the appropriate section, and link the PR.
